Selected work

  1. 01 2026 – now Co-founder

    Futsalaki

    A mobile app for organising and joining pickup futsal games in Cyprus. Players find a game near them, grab a spot and pay in the app. Organisers stop chasing people for cash on WhatsApp — the money reaches them automatically.

    I run the company with Panayiotis Charalambous. On the engineering side I’ve spent most of my time on the parts users never see but would notice if they broke: the payment flow, database permissions, rate limiting, error monitoring, and a CI pipeline that won’t let a leaked key reach production.

    React Native (Expo) · Supabase / Postgres · Stripe Connect · Google sign-in · GitHub Actions

    Open the demo futsalaki.com

  2. 02 2026 Co-developer

    SSSB Market

    Every August thousands of students move into SSSB housing in Stockholm and every June they move out, and the furniture mostly ends up in the bin room. SSSB Market is a board where they sell it to each other instead, starting with Lappis.

    Posting takes a minute and needs no account: a few photos, a price, a WhatsApp number. Buyers tap to chat. The seller gets a private link to edit the listing or mark it sold, and old listings disappear after 60 days so the board stays current. Photos are compressed on the phone before upload, posting is rate-limited, and there’s a small moderation page. English and Swedish. Built with Antreas Patsiantos.

    Next.js · React · TypeScript · Prisma · Supabase (Postgres + Storage) · Tailwind

    Open the demo

  3. 03 In progress Solo

    CourtSense Badminton AI coach

    Film a rally on your phone, get back an honest account of how you moved. CourtSense tracks the player’s pose frame by frame, calibrates the court automatically so positions map onto real court coordinates, and turns that into footwork and coverage stats. A language model then writes the feedback a coach would give.

    I’ve played badminton for Cyprus for years and been told what my footwork looks like more times than I can count. I wanted to see it for myself.

    Python · FastAPI · OpenCV · pose estimation · Claude API

    Demo when it’s ready.

  4. 04 2026 KTH coursework

    Algorithms & data structures in C

    Stacks, binary search trees, heaps, hash tables and graphs, written from scratch with no libraries and benchmarked against each other. The graph assignment finds the fastest train route between any two stations in Sweden and across Europe using Dijkstra’s algorithm; the hashing one looks up every Swedish postcode.

    C · benchmarking · Dijkstra · hashing · priority queues

About
